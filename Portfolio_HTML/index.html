À propos de moi

Bonjour ! Je m'appelle Lina. Je suis stagiaire en développement digital et je commence à découvrir la création de sites web. J'aime apprendre de nouvelles choses et comprendre comment fonctionnent les pages Internet.

J'ai choisi cette formation parce que je souhaite apprendre à créer mes propres sites et, plus tard, développer des applications web. Pour le moment, je m'entraîne surtout à structurer mes pages avec HTML.

Ce que j'apprends

Les technologies que je découvre

  • HTML5 : structurer le contenu d'une page web.
  • CSS3 : apprendre à mettre en forme les pages.
  • JavaScript : découvrir l'interactivité.
  • PHP : explorer la programmation côté serveur.

Mes objectifs d'apprentissage

  1. Créer une page HTML bien structurée.
  2. Construire un site composé de plusieurs pages.
  3. Apprendre à présenter un site avec CSS.
  4. Créer une application web complète.
